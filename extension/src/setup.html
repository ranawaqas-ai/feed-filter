Set up Feed Filter

Feed Filter blurs YouTube home and sidebar cards until Jev has checked each video against your goals. Until setup is finished, YouTube looks as usual.

1Your Jev key

Create a key at console.typesafe.ai/keys. Calls are billed to your TypeSafe account.

Stored only in this Chrome profile and sent only to api.typesafe.ai. Anyone with access to this profile can read it.

2Your goals

Pick at least one, edit the wording, or write your own. Each video is checked against every goal you keep, and the best match decides what you see. Wording works best as "what you want. Not: what to leave out."

3Daily call limit

One call per video per goal. A long evening on YouTube with three goals can use a few thousand. TypeSafe has no per-key spending limit, so this is the guard.

You're set

Open YouTube, or reload a YouTube tab that is already open.
